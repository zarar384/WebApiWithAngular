# PaymentApp

Angular + ASP.NET Core application.

## Run

```bash
npm run dev
```

## URLs

- Frontend: http://localhost:4200
- Backend: http://localhost:61236

## First run

```bash
cd client
npm install
```

## Structure

/client - Angular  
/server - ASP.NET API  

## Run separately

Frontend:

```bash
cd client
npm start
```

Backend:

```bash
cd server/PaymentApp/PaymentApp
dotnet run
```

## Notes

- Database is created automatically
- Development only setup
